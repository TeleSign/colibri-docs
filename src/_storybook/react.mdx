# Colibri Design System

## Welcome

Colibri is a themeable Web Components library built with Lit, designed to provide a consistent and customizable design system for your web applications. This guide shows you how to integrate Colibri into a React project.

## Current Versions

- **Colibri:** {packageJson.dependencies['@telesign/colibri']}
- **Colibri-icons:** {packageJson.dependencies['@telesign/colibri-icons']}

## Quick Start

Install the packages:

```bash
npm install @telesign/colibri @telesign/colibri-icons
```

## Registering Components

```typescript
  import {
    registerColibriComponents,
    registerAllComponents,
    ColButton,
    ColTextField,
  } from '@telesign/colibri';
  import { ColIcon } from '@telesign/colibri-icons';
  import '@telesign/colibri/styles/styles.css';

  // Option 1: Register specific components
  registerColibriComponents([ColButton, ColTextField]);

  // Option 2: Register all Colibri components
  registerAllComponents();
```

## Theme Management

Our theme system provides a powerful and flexible way to customize the visual appearance of components across different contexts, brands, and user preferences. Built on a foundation of design tokens and CSS custom properties, themes enable consistent styling while maintaining the flexibility to adapt to diverse design requirements. For more information, please read our [Themes page](http://localhost:6006/?path=/docs/foundation-themes--overview).

To get it set working with one of our "out-of-the-box" themes, here we show you how to set it up:

```typescript
  import React from 'react';

  export interface ThemeProviderProps {
    theme?: 'default' | 'massive';
    children: React.ReactNode;
  }

  export const ThemeProvider: React.FC<ThemeProviderProps> = ({ theme = 'default', children }) => {
    return <div data-theme={theme}>{children}</div>;
  };
```

Integrating Colibrí components into your React JSX is very straightforward, please take a look at the following sample code snippet to use ColTextField:

```typescript
import React, { useState } from 'react';

function MyComponent() {
  const [username, setUsername] = useState('');

  const handleInput = (event: Event) => {
    const target = event.target as HTMLInputElement;
    setUsername(target.value);
  };

  return (
    <div>
      <col-text-field
        label="Username"
        name="username"
        value={username}
        onInput={handleInput}
        placeholder="Enter your username"
      >
      </col-text-field>
    </div>
  );
}
```


## Using with Forms

```typescript
function LoginForm() {
  const handleSubmit = (event: React.FormEvent) => {
    event.preventDefault();
    const formData = new FormData(event.target as HTMLFormElement);

  return (
    <form onSubmit={handleSubmit}>

      <col-button type="submit">Login</col-button>
    </form>
  );
}
```

## Autocompletion

To enable autocompletion, type checking, and a seamless developer experience when using Lit components in React, wrap them with `createComponent` from `@lit/react`. This generates React-friendly components with proper typings.

**Note:** React 18/19 have limited native support for custom elements props and events in JSX. Using wrappers is recommended to get full typing benefits and avoid issues with autocompletion or type inference when using raw web components. Some custom events may still require manual type handling or event listeners via refs.

- Install the package by running:

```bash
npm install @lit/react
```

- Create a new React component file, import the createComponent helper and wrap the component using the required options:

```ts
  import React from 'react';
  import { createComponent } from '@lit/react';
  import { ColButton } from '@telesign/colibri';

  export const Button = createComponent({
    tagName: 'col-button',
    elementClass: ColButton,
    react: React,
    events: {
      onClick: 'click',
      onSubmit: 'submit',
      onReset: 'reset',
    },
  });
```

- Use the new component in your JSX:

```ts
  import React from 'react';
  import { Button } from './components/Button';

  function Example() {
    return <Button disabled={true} type="button" />;
  }
```

For more details, visit the official documentation: [Lit + React Integration Guide](https://lit.dev/docs/frameworks/react/#createcomponent)

## Using Slots

Lit components use the `<slot>` element to enable content projection. When using Colibri components inside React, you can pass children normally to take advantage of this feature.

**Example using a slot:**

```ts
  import React from 'react';

  function BadgeExample() {
    return (
      <col-badge variant="default">
        {/* Icon slot */}
        <div slot="icon" style={{ display: 'contents' }}>
          <Icon name="emoji-circle" size="12" />
        </div>

        Default Badge
      </col-badge>
    );
  }

  export default BadgeExample;
```
