    <Title>Radio Button</Title>
    The Colibri Radio Button component provides a more visually prominent and touch-friendly alternative to standard radio inputs. It's ideal for interfaces where selection options should be emphasized and have greater visual weight, such as in filter controls, preference settings, or configurable dashboards.

    <Subtitle>How to use it</Subtitle>
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColRadioButton } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColRadioButton]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <!-- Basic radio button -->
        <col-radio-button value="option1">
          <col-icon name="emoji-circle" slot="icon"></col-icon>
          Option 1
        </col-radio-button>

        <!-- Radio button with string label -->
        <col-radio-button value="option2" label="Option 2">
          <col-icon name="emoji-circle" slot="icon"></col-icon>
        </col-radio-button>

        <!-- Radio button with custom label -->
        <col-radio-button value="option3" customlabel>
          <col-icon name="emoji-circle" slot="icon"></col-icon>
          <span slot="label">Custom <strong>formatted</strong> label</span>
        </col-radio-button>

        <!-- Radio button group -->
        <col-radio-button group="options" value="option1" checked>
          <col-icon name="emoji-circle" slot="icon"></col-icon>
          Option 1
        </col-radio-button>
        <col-radio-button group="options" value="option2">
          <col-icon name="emoji-circle" slot="icon"></col-icon>
          Option 2
        </col-radio-button>
        ```

    <Subtitle>When to use it</Subtitle>
    Radio Buttons are used when users need to select one option from a mutually exclusive set of choices, with enhanced visual prominence. Here are some common use cases:

    - **Filter Controls** - When users need to choose one filter option with visual emphasis
    - **Preference Settings** - For configuration options where visual weight is important
    - **Dashboard Configuration** - For selecting display options or layout preferences
    - **Touch Interfaces** - When larger, more prominent selection controls are needed
    - **Visual Selection** - When options need to be visually distinct and easily scannable
