    <Title>Checkbox</Title>
    Checkboxes are used for multiple choices, not for mutually exclusive choices. Each checkbox works independently from other checkboxes in the list, therefore checking an additional box does not affect any other selections.

    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, ColCheckbox } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web component:
        ```typescript
        registerColibriComponents([ColCheckbox]);
        ```
    4. Use it in your HTML:
        ```html
        <col-checkbox ?disabled=${disabled}>
          Default checkbox
        </col-checkbox>
        ```

    ## When to use it
    The "Checkbox" component is a common and versatile user interface element used to allow users to select one or more options from a list:

    - **Forms:** checkboxes are used to allow users to select multiple options from a list.
    - **Filters:** Checkboxes are used to allow users to filter content by categories, attributes or tags.
    - **Settings:** Check boxes are used to allow users to enable or disable features, set language preferences, etc.
    - **Item selection:** In file management applications, checkboxes are used to allow users to select multiple items to perform actions such as delete, move or set the action according to the functionalities of their design.
    - Use the indeterminate state when the checkbox contains a sublist of selections, some of which are selected, and some unselected. In addition to default, selected, and indeterminate states, checkboxes also have states for hover, active, focus and disabled.

    ## Accessibility

    The checkbox component follows accessibility best practices:

    - Uses proper ARIA attributes (`role="checkbox"`, `aria-checked`, `aria-disabled`)
    - Supports keyboard navigation and interaction (Space and Enter keys)
    - Maintains proper focus states
    - Provides appropriate visual states (checked, unchecked, indeterminate, disabled)
