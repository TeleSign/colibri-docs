    The Colibri Breadcrumb component provides a navigation container that displays a trail of links to help users understand their current location within a website or application hierarchy. It works in conjunction with `col-breadcrumb-item` components to create a complete navigation trail.

    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColBreadcrumb, ColBreadcrumbItem } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColBreadcrumb, ColBreadcrumbItem]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-breadcrumb>
          <col-breadcrumb-item>Home</col-breadcrumb-item>
          <col-breadcrumb-item>Products</col-breadcrumb-item>
          <col-breadcrumb-item current>Details</col-breadcrumb-item>
        </col-breadcrumb>
        ```

    The breadcrumb container:
    - Provides semantic navigation structure
    - Manages separator consistency across all items
    - Ensures proper accessibility attributes
    - Maintains visual consistency

      You can customize the separator character displayed between breadcrumb items using the `separator` property. This allows you to match your design system's visual language.
    </div>

    Popular separator options include:
    - `/` (default) - Forward slash
    - `>` - Greater than symbol
    - `→` - Arrow
    - `•` - Bullet
    - `|` - Pipe
    - `»` - Double angle quote
    - `-` - Dash

    ## Accessibility

    The Breadcrumb container component includes several built-in accessibility features:

    - **Semantic HTML** - Uses `<nav>` element to identify the breadcrumb as a navigation landmark
    - **ARIA label** - Customizable `aria-label` attribute for the navigation element (defaults to "Breadcrumb navigation")
    - **Screen reader support** - Includes hidden "You are here:" text for screen reader users
    - **Keyboard navigation** - Ensures all interactive breadcrumb items are keyboard accessible

    Best practices:
    - Use descriptive aria-labels when multiple breadcrumbs exist on a page
    - Ensure breadcrumb items have sufficient color contrast
    - Keep the breadcrumb trail concise and logical
    - Always mark the current page item with the `current` attribute
