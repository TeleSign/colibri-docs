    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColBreadcrumb, ColBreadcrumbItem } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColBreadcrumb, ColBreadcrumbItem]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-breadcrumb>
          <col-breadcrumb-item href="/">Home</col-breadcrumb-item>
          <col-breadcrumb-item href="/products">Products</col-breadcrumb-item>
          <col-breadcrumb-item current>Product Details</col-breadcrumb-item>
        </col-breadcrumb>
        ```

    ### With router integration
    <div>
      For single-page applications, use the `router` property along with the `breadcrumb-click` event to handle navigation without page refreshes.
    </div>

    <Canvas of={ColBreadcrumbStories.WithRouter} />

    When `router` is set to `true`, clicking a breadcrumb item will:
    1. Prevent the default link navigation
    2. Emit a `breadcrumb-click` event with navigation details
    3. Allow your application router to handle the navigation

    Example event handler:
    ```javascript
    document.addEventListener('breadcrumb-click', (event) => {
      const { value, label, index, href } = event.detail;
      // Handle navigation with your router
      router.navigate(href || value);
    });
    ```

    ## Properties

    ### col-breadcrumb

    | Property | Type | Default | Description |
    |----------|------|---------|-------------|
    | `ariaLabel` | `string` | `'Breadcrumb navigation'` | Accessibility label for the navigation element |
    | `separator` | `string` | `'/'` | Character or string used to separate breadcrumb items |

    ### col-breadcrumb-item

    | Property | Type | Default | Description |
    |----------|------|---------|-------------|
    | `href` | `string` | `''` | URL for the breadcrumb link |
    | `current` | `boolean` | `false` | Indicates if this is the current page |
    | `separator` | `string` | `'/'` | Separator character (inherited from parent) |
    | `newTab` | `boolean` | `false` | Opens the link in a new tab |
    | `value` | `string` | `''` | Value passed in the breadcrumb-click event |
    | `router` | `boolean` | `false` | Enables router mode for SPA navigation |

    ## Events

    ### breadcrumb-click

    Emitted when a breadcrumb item is clicked. The event detail contains:

    ```typescript
    interface BreadcrumbClickDetail {
      value: string;     // The value prop of the clicked item
      label: string;     // The text content of the clicked item
      index: number;     // The index of the item in the breadcrumb
      href?: string;     // The href if provided
    }
    ```

    ## Accessibility

    The Breadcrumb component includes several accessibility features:

    - **ARIA navigation landmark** - The breadcrumb is wrapped in a `<nav>` element with an appropriate `aria-label`
    - **Screen reader support** - Includes "You are here:" text for screen readers
    - **Current page indication** - The current page is marked with `aria-current="page"`
    - **Keyboard navigation** - All interactive items are keyboard accessible
    - **Semantic HTML** - Uses appropriate HTML elements for structure

    Best practices:
    - Always mark the current page with the `current` attribute
    - Provide meaningful link text that makes sense out of context
    - Keep breadcrumb trails concise and logical
    - Ensure sufficient color contrast for separators and links
