    <Title>Avatar</Title>
    The Colibri Avatar component is used to visually identify and represent a user or entity in a user interface. Its main purpose is visual identification. It provides a graphical representation that helps to quickly and visually identify a user or entity in the application.

    <Subtitle>How to use it</Subtitle>
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColAvatar } from '@telesign/colibri';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColAvatar]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-avatar avatarName="John Doe"></col-avatar>
        ```

    <Subtitle>When to use it</Subtitle>
    Here are some common use cases:

    - **User Profiles** - In areas where a user's profile information is displayed.
    - **Comments and Messages** - Next to comments, posts or messages to identify the author.
    - **Lists and Groups** - In lists of users or groups to show the profile picture of each member.
    - **Chat and Messaging** - In chat applications to show the profile image of the sender or receiver of messages.
    - **Content Management System** - In administration panels to identify content authors or contributors.
