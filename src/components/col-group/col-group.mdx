    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColGroup, ColTypography } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColGroup, ColTypography]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-group orientation="horizontal">
          <col-button variant="primary">Save</col-button>
          <col-button variant="secondary">Cancel</col-button>
        </col-group>
        ```

    ## When to use it
    Here are common use cases for the Group component:

    - **Button groups** - Organize related actions like Save/Cancel or navigation buttons
    - **Form sections** - Group related form inputs with a descriptive label
    - **Radio/Checkbox groups** - Create accessible groups of selectable options
    - **Toolbar items** - Organize toolbar actions with consistent spacing
    - **Navigation elements** - Group navigation links or tabs together
    - **Settings panels** - Organize related configuration options

    ## Accessibility

    The Group component includes several accessibility features:

    - **Semantic HTML** - Uses appropriate role attributes (default: "group", customizable)
    - **Label association** - Labels are properly associated using `aria-labelledby`
    - **Helper text** - Helper text is associated using `aria-describedby`
    - **Keyboard navigation** - Maintains natural tab order through grouped elements
    - **Screen reader support** - Announces group context and relationships

    Best practices:
    - Use descriptive labels for groups containing form controls
    - Set `role="radiogroup"` for radio button groups
    - Ensure all interactive elements within groups are keyboard accessible
    - Provide helper text when the group's purpose isn't immediately clear
    - Test with screen readers to ensure proper announcement

    Special considerations:
    - Form sections benefit from clear, descriptive labels
    - Complex nested groups should maintain a logical structure
