    <Title>Radio</Title>
    The Colibri Radio component is used for single selection within a group of options, allowing users to choose one option from a mutually exclusive set.

    <Subtitle>How to use it</Subtitle>
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColRadio } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColRadio]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <!-- Basic radio button -->
        <col-radio value="option1">Option 1</col-radio>

        <!-- Radio button with custom label -->
        <col-radio value="option2" customlabel>
          <span slot="label">Custom <strong>formatted</strong> label</span>
        </col-radio>

        <!-- Radio group -->
        <col-radio name="group1" value="option1" group="group1">Option 1</col-radio>
        <col-radio name="group1" value="option2" group="group1">Option 2</col-radio>
        ```

    <Subtitle>When to use it</Subtitle>
    Radio buttons are used when users need to select one option from a mutually exclusive set of choices. Here are some common use cases:

    - **Form Selection** - When users need to choose one option from a predefined list
    - **Settings and Preferences** - For configuration options where only one choice is allowed
    - **Survey Questions** - For single-choice questions in forms or surveys
    - **Navigation Options** - When users need to select one navigation path
    - **Filtering and Sorting** - For selecting one filter or sort option at a time
