    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, ColToggle } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web component:
        ```typescript
        registerColibriComponents([ColToggle]);
        ```
    4. Use it in your HTML:
        ```html
        <col-toggle>Enable Notifications</col-toggle>
        ```

    ## When to use it
    The toggle component is a simple yet powerful UI element that allows users to switch between two states, such as on/off, active/inactive, or enabled/disabled. It is commonly used for settings, preferences, and various interactive controls:

    - **Enabling and Disabling Features:** A toggle used to turn features or settings on and off.
    - **Privacy Settings:** A toggle for managing privacy settings and permissions.
    - **Account Management:** A toggle for managing account preferences.
    - **Content Preferences:** A toggle for selecting content preferences.
    - **Notification Settings:** A toggle for managing notification preferences.
    - **User Interface Customization:** A toggle for customizing the user interface.
    - **Security and Privacy Controls:** A toggle for security and privacy-related controls.

    ### Differences from checkbox
    Checkboxes and toggles are both user interface elements for binary choices, but they differ in their intended use and the user experience they convey.
    - **Checkboxes** are typically used for selecting multiple options from a list.
    - **Toggles** are used for immediate on/off actions.

    ## Accessibility

    The toggle component follows accessibility best practices:

    - Uses proper ARIA attributes (`role="checkbox"`, `aria-checked`, `aria-disabled`)
    - Supports keyboard navigation and interaction (Space and Enter keys)
    - Maintains proper focus states
    - Provides appropriate visual states (checked, unchecked, disabled)
