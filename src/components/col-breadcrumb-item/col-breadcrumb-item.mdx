    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColBreadcrumb, ColBreadcrumbItem } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColBreadcrumb, ColBreadcrumbItem]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-breadcrumb>
          <col-breadcrumb-item href="/">Home</col-breadcrumb-item>
          <col-breadcrumb-item href="/products">Products</col-breadcrumb-item>
          <col-breadcrumb-item current>iPhone 15</col-breadcrumb-item>
        </col-breadcrumb>
        ```

    ## When to use it
    Use Breadcrumb Item components to:

    - **Create navigation links** - Each item can link to a parent page in the hierarchy
    - **Show current location** - Mark the current page with the `current` attribute
    - **Handle SPA navigation** - Use router mode for client-side routing
    - **Provide contextual navigation** - Help users move up the site hierarchy

    Different configurations:
    - **Text only** - For non-interactive current page indicators
    - **With href** - For standard page navigation
    - **With router** - For single-page application navigation
    - **With newTab** - For opening links in new browser tabs

    ### Router navigation
    <div>
      For single-page applications, use the `router` property to handle navigation without page refreshes. This prevents default link behavior and emits an event instead.
    </div>

    <Canvas of={ColBreadcrumbItemStories.RouterNavigation} />

    Router mode features:
    - Prevents default link navigation
    - Emits `breadcrumb-click` event with navigation details
    - Maintains link appearance and accessibility
    - Works with or without `href` attribute

    Example event handler:
    ```javascript
    document.addEventListener('breadcrumb-click', (event) => {
      const { value, label, index, href } = event.detail;
      // Handle navigation with your router
      myRouter.navigate(value || href);
    });
    ```

    ## Events

    ### breadcrumb-click

    The `breadcrumb-click` event is emitted when a breadcrumb item is clicked. This event bubbles and is composed, so it can be handled at any parent level.

    **Event detail structure:**
    ```typescript
    interface BreadcrumbClickDetail {
      value: string;     // The value prop of the clicked item
      label: string;     // The text content of the clicked item
      index: number;     // The index position within the breadcrumb
      href?: string;     // The href if provided
    }
    ```

    **Example usage:**
    ```javascript
    // Handle at item level
    item.addEventListener('breadcrumb-click', (e) => {
      console.log('Clicked:', e.detail.label);
    });

    // Handle at container level
    breadcrumb.addEventListener('breadcrumb-click', (e) => {
      if (e.detail.value === 'home') {
        router.navigate('/');
      }
    });
    ```

    ## Accessibility

    The Breadcrumb Item component includes built-in accessibility features:

    - **Semantic HTML** - Uses appropriate elements (`<a>` for links, `<span>` for text)
    - **Current page indication** - Uses `aria-current="page"` for the current item
    - **Keyboard navigation** - All interactive items are focusable and activatable via keyboard
    - **Screen reader support** - Proper link context and current page announcement
    - **Focus indicators** - Clear visual focus states for keyboard navigation

    Best practices:
    - Use descriptive, concise text for each breadcrumb item
    - Always mark the current page with the `current` attribute
    - Ensure sufficient color contrast between text and background
    - Keep breadcrumb text short to prevent wrapping on mobile devices
