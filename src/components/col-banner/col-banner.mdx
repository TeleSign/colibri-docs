    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        npm install @telesign/colibri-icons
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColBanner, ColButton, ColGroup } from '@telesign/colibri';
        import { ColIcon } from '@telesign/colibri-icons';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColBanner, ColButton, ColGroup, ColIcon]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-banner variant="info">
          <span slot="title">Title</span>
          Lorem ipsum dolor sit amet, consectetur adipisicing elit.
          <col-group slot="actions">
            <col-button color="primary" variant="outlined"> Button </col-button>
            <col-button color="primary" variant="plain"> Button </col-button>
          </col-group>
        </col-banner>
        ```

    ## When to use it
    The `col-banner` component is a visual tool used to grab the user's attention and communicate important messages in a prominent way. Some use cases are described below:

    - **System Updates**: Inform users of scheduled maintenance, software upgrades, or service changes.
    - **Security Alerts**: Communicate security issues or important warnings that require the user's immediate attention.
    - **Product Launches**: Highlight new products or services available to attract users' attention.
    - **Policy Changes**: Inform about updates to privacy policies, terms of service, or any significant changes to the terms of use.
    - **Critical Errors**: Inform users of critical errors that affect the functionality of the platform and provide steps for resolution.
    - **Confirmations**: Display confirmation messages for successfully completed actions.

    To close the banner there are 3 ways to do it:
    - The `click` action on the close button dispatch the `banner-closed` event.

    ## Accessibility
    The `col-banner` can be searched up or placed under an element that needs to be classified categorically.  They can help group similar elements by color and group names.

    - **Keyboard Navigation:** Fully navigable using Tab. All interactive elements (element and buttons) are accessible via keyboard.
    - **Actions Supported:** The component handles `@keydown` and `@click`.
    - **Display:** Banners should be displayed at the top of the screen, below a top app bar. They’re persistent and nonmodal, allowing the user to either ignore them or interact with them at any time. <ins>Only one banner should be shown at a time</ins>.
    - **Best Practices:**
      - Make sure you include the `slot='title'` and `slot='actions'` in order to display correctly the Title and Actions sections on the Banner.
