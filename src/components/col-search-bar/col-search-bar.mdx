  ## How to use it

  1. Install the package:
      ```bash
      npm install @colibri/colibri-components
      ```

  2. Import the dependencies:
      ```ts
      import { registerColibriComponents, ColSearchBar } from '@telesign/colibri';
      import '@telesign/colibri/styles/styles.css';
      ```

  3. Register the components:
      ```ts
      registerColibriComponents([ColSearchBar]);
      ```

  4. Use it in your HTML:
      ```html
      <col-search-bar placeholder="Search..." variant="static"></col-search-bar>
      ```

  ## When to use it

  Use the `col-search-bar` when you need a lightweight, interactive search input. Ideal use cases include:

  - **Search functionality** in toolbars or filters.
  - **Expandable search inputs** that save space by default.
  - **Forms or modals** that require compact input for search.
