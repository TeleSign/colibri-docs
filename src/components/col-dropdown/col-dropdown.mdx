    ## How to use it

    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, ColDropdown } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web component:
        ```typescript
        registerColibriComponents([ColDropdown]);
        ```
    4. Use it in your HTML:
        ```html
        <col-dropdown>
          <button slot="trigger">Toggle</button>
          <div>Content</div>
        </col-dropdown>
        ```

    ## When to use it

    A dropdown menu is a compact way of displaying multiple choices. It appears upon interaction with an element (such as an icon or button) or when users perform a specific action.

    The dropdown component is a versatile and commonly used UI element that allows users to select an option from a list. It is particularly useful for conserving space and providing a clean interface when presenting multiple choices. Here are various use cases demonstrating the application of the dropdown component in different scenarios:

    * **Form Fieldss**: A dropdown used to provide selectable options for form fields. For example: A user fills out a registration form and selects their country from a dropdown list, ensuring consistency and reducing input errors.
    * **Navigation Menus**: A dropdown used for navigating between different sections or pages within an application. For example: A user clicks on a navigation menu item and selects a sub-page or section from the dropdown list.
    * **Settings and Preferences**: A dropdown for adjusting user settings and preferences. For example: A user opens the settings panel and selects their preferred language or theme from a dropdown.
    * **Filter Options**: A dropdown used to filter data or content based on specific criteria. For example: A user selects a category from a dropdown to filter products displayed on an e-commerce site.
    * **Profile and Account Management**: A dropdown for managing profile and account-related actions. For example: A user clicks on their profile icon and selects "Account Settings" or "Log Out" from the dropdown.
    * **Project and Task Management**: A dropdown for selecting projects or tasks within a management tool. For example: A user managing multiple projects selects the current project they are working on from a dropdown.
    * **Content Creation Tools**: A dropdown used to format text or insert media in content creation tools. For example: A user writing a blog post selects the font style from a dropdown menu.
    * **Data Entry**: A dropdown to assist with data entry by providing predefined options. For example: An admin entering data into a system selects the department from a dropdown list to ensure consistency.
    * **Calendar and Date Selection**: A dropdown for selecting dates or times. For example: A user schedules a meeting and selects the date and time zone from dropdown menus.
    * **Multi-Select Options**: A dropdown allowing users to select multiple options. For example: A user fills out their profile and selects multiple interests or skills from a multi-select dropdown.
