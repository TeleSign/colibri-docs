    <h2>Grouping Radio Cards</h2>
    <p>
      Radio cards that belong together should share the same <code>group</code> attribute.
      This ensures that only one radio card in the group can be selected at a time.
    </p>

    <h2>Content Types</h2>
    <p>
      Radio cards support two primary content patterns:
    </p>
    <ul>
      <li><strong>Title/Description:</strong> The default pattern with structured content fields</li>
      <li><strong>Custom Content:</strong> Using the <code>customContent</code> property to enable full content control</li>
    </ul>

    <h2>Layout Considerations</h2>
    <p>
      When using Radio Cards:
    </p>
    <ul>
      <li>Arrange cards in a grid or list depending on the content complexity and available space</li>
      <li>Maintain consistent sizing across all cards in a group</li>
      <li>Consider responsive layouts that adapt to different screen sizes</li>
    </ul>

    <h2>Accessibility</h2>
    <p>
      Radio Card components follow WAI-ARIA best practices for accessibility:
    </p>
    <ul>
      <li>Uses proper <code>role="radio"</code> and <code>aria-checked</code> attributes</li>
      <li>Supports keyboard navigation with focus indicators</li>
      <li>Associates labels with controls via aria attributes</li>
      <li>Maintains sufficient contrast in all states</li>
    </ul>
