    <Title>Radio Card</Title>
    The Colibri Radio Card component is a selectable input that functions like a radio button but is presented in the form of a card. This allows for richer content and a larger target area, making it ideal for choices that need more explanation or visual emphasis.

    <Subtitle>How to use it</Subtitle>
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { ColRadioCard, registerColibriComponents } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColRadioCard]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <!-- Basic radio card -->
        <col-radio-card value="1" title="Option 1" description="A brief description of this option."></col-radio-card>

        <!-- Radio card group -->
        <col-radio-card-group>
            <col-radio-card value="a" title="Option A" description="Description for A."></col-radio-card>
            <col-radio-card value="b" title="Option B" description="Description for B." checked></col-radio-card>
        </col-radio-card-group>

        <!-- Radio card with custom content -->
        <col-radio-card value="custom" customcontent>
          <div style="display: flex; flex-direction: column; align-items: center; padding: 1rem;">
            <img src="https://via.placeholder.com/80" alt="placeholder" />
            <h4>Custom Plan</h4>
            <p>This plan has a custom layout.</p>
          </div>
        </col-radio-card>
        ```

    <Subtitle>When to use it</Subtitle>
    Use Radio Cards when you need to present a set of mutually exclusive options that require more than a simple text label.
    - **Feature Comparison:** Ideal for pricing tables or subscription tiers where each option has multiple features to display.
    - **Visual Choices:** When the options are best represented by images or icons, such as selecting a style or theme.
    - **Onboarding Flows:** To guide users through a setup process by having them select their preferences from a clear, visually distinct set of options.
    - **Complex Forms:** In forms where a choice has significant implications that need to be explained, a radio card provides the necessary space.
