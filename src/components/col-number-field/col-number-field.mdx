    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColNumberField } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```

        <Callout variant="info" icon="ℹ️">
          **Dependency Note:** The `col-number-field` component depends on the `col-icon` component for rendering increment/decrement buttons and optional leading icons. These component is registered automatically as a dependency of the `col-number-field`component, so there's no need to import them.
        </Callout>

    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColNumberField]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-number-field
          id="quantity"
          name="quantity"
          label="Quantity"
          value="5"
          min="1"
          max="100"
          step="1"
        ></col-number-field>
        ```

    ## When to use it

    The `col-number-field` component is the standard choice for numeric inputs that require user-friendly controls and validation. Use it when you need to:

    - **Collect Numeric Data**: Gather quantities, amounts, percentages, or any numeric values with constraints.
    - **Provide Increment/Decrement Controls**: Offer intuitive buttons for adjusting values without manual typing.
    - **Enforce Constraints**: Apply min/max limits, step values, and precision requirements.
    - **Format Values**: Display numbers as currency, percentages, or formatted numbers with proper localization.
    - **Build Forms**: Integrate seamlessly into HTML forms for data submission and validation.
    - **Ensure Accessibility**: Provide proper ARIA attributes and keyboard navigation for all users.
