    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColToolbar } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColToolbar]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <!-- Basic toolbar with actions -->
        <col-toolbar>
          <button>New</button>
          <button>Edit</button>
          <button>Delete</button>
        </col-toolbar>

        <!-- Application header toolbar -->
        <col-toolbar align="space-between" border="bottom" elevation sticky="top">
          <div>
            <h1>MyApp</h1>
            <nav>Dashboard › Analytics</nav>
          </div>
          <div>
            <input type="search" placeholder="Search..." />
            <button>Profile</button>
          </div>
        </col-toolbar>

        <!-- Form actions toolbar -->
        <col-toolbar align="right" border="top" gap="large">
          <button>Cancel</button>
          <button>Save Draft</button>
          <button>Publish</button>
        </col-toolbar>

        <!-- Responsive toolbar with wrapping -->
        <col-toolbar wrap gap="medium" border="bottom">
          <button>Action 1</button>
          <button>Action 2</button>
          <button>Action 3</button>
          <input type="search" placeholder="Search..." />
          <button>Settings</button>
        </col-toolbar>
        ```

    ## When to use it
    The Toolbar component provides structured layouts for various interface patterns and use cases:

    ### Primary Use Cases

    **Application Headers**
    - Top navigation bars with branding, menu items, and user controls
    - Breadcrumb navigation with search and global actions
    - Multi-level headers with different sections and alignments

    **Data Management Interfaces**
    - Table action bars with CRUD operations (Create, Read, Update, Delete)
    - Filtering and search controls above data lists
    - Bulk action toolbars for selected items

    **Form and Content Toolbars**
    - Form action buttons (Save, Cancel, Submit)
    - Rich text editor formatting tools
    - Content creation and editing controls

    **Dashboard and Analytics**
    - Dashboard headers with time range selectors and export options
    - Report generation controls and filters
    - Status indicators and real-time information displays

    **Mobile and Responsive Interfaces**
    - Collapsible navigation bars for small screens
    - Bottom action bars for mobile apps
    - Adaptive toolbars that wrap content on narrow viewports

    ### Alignment Patterns

    **Left Alignment (`align="left"`)**
    - Primary actions and navigation elements
    - Sequential workflow buttons
    - Default toolbar behavior

    **Right Alignment (`align="right"`)**
    - Secondary actions and settings
    - User profile and account controls
    - Form submission buttons

    **Center Alignment (`align="center"`)**
    - Modal dialog actions
    - Simple confirmation buttons
    - Symmetrical button groups

    **Space Between (`align="space-between"`)**
    - Application headers with logo and user menu
    - Content with primary and secondary action groups
    - Navigation with breadcrumbs and controls

    **Space Around (`align="space-around"`)**
    - Tab-like navigation elements
    - Evenly distributed menu items
    - Balanced action groups

    ### Positioning Strategies

    **Static Positioning (default)**
    - Content-embedded toolbars
    - Form sections and panels
    - Inline action bars

    **Sticky Positioning**
    - Table headers that stick during scroll
    - Section toolbars within containers
    - Context-sensitive action bars

    **Fixed Positioning**
    - Global application headers
    - Persistent bottom action bars
    - Always-visible controls

    ### Best Practices

    **Content Organization**
    - Group related actions together using visual dividers
    - Place primary actions prominently (left side or right side depending on context)
    - Use consistent spacing and alignment patterns across the application

    **Responsive Design**
    - Enable wrapping for toolbars with many items
    - Use appropriate gap sizes for different screen sizes
    - Consider mobile-first design with essential actions prioritized

    **Accessibility**
    - Ensure proper tab order for keyboard navigation
    - Use semantic HTML elements within toolbar slots
    - Provide adequate touch targets for mobile interfaces (minimum 44px)

    **Performance**
    - Avoid excessive nesting of complex components within toolbars
    - Use appropriate positioning (sticky vs fixed) based on actual needs
    - Consider lazy loading for non-critical toolbar content
