    ## How to use it

    ### Installation
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, ColTooltip } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web component:
        ```typescript
        registerColibriComponents([ColTooltip]);
        ```
    4. Use it in your HTML:
        ```html
        <col-tooltip>
          Text, Icon or Label
          <div slot="tooltip-content">
            Tooltip Content
          </div>
        </col-tooltip>
        ```
    ### Behavior

    The container of the tooltip may be aligned to start, center or end to keep the container from bleeding off the page or covering important information. The UI trigger button and caret tip should be vertically center with each other to clearly associate the tooltip and the trigger. This is especially helpful when multiple elements are close to each other.

    ### Content

    - Should contain relevant, specific content.
    - Keep tooltips short and concise, no longer than a sentence or two.
    - Should not contain required information essential for a user to complete their task since a tooltip is not persistent.
    - Use sentence-style capitalization and write the text as full sentences with punctuation, unless space is limited.
    - Icon button tooltips that describe a button’s function should only contain one or two words.

    ### Alignment

    **Mouse**

    Tooltips are triggered when the mouse hovers over or focuses on the UI trigger. The tooltip persists as long as the mouse remains over the active container or the UI trigger. The tooltip is dismissed by hovering away or moving focus to another element. Definition tooltip can additionally be activated on click or enter and dismissed by clicking outside of active container or UI element.

    **Keyboard**

    Users can trigger a tooltip by focusing on element. Additionally, a definition tooltip can be triggered by using the `enter` key. A tooltip dismissible by use of the `escape` key.


    ## When to use it
    The Tooltip component is a small pop-up window that provides additional information about an element when the user hovers over it or touches it. Tooltips are useful for providing explanations, definitions or details without cluttering the main interface. Here are some common use cases for the Tooltip component:

    * **Icon Labels**
        - **Icon Descriptions**: When icons are used instead of text for buttons or options, a tooltip can provide the icon description to improve accessibility and user understanding.
        - **Keyboard Shortcuts**: Show available keyboard shortcuts for actions that can be performed via icons.
    * **Form Field Explanations**
        - **Input Fields**: Provide additional information or examples about what is expected in a specific input field.
        - **Error Messages**: Explain why an input field is invalid when the user hovers over the field after an error message is displayed.
    * **Product Information**
        - **Specifics**: On an e-commerce site, provide additional details or product specifications when hovering over the product name or image.
        - **Special Offers**: Show additional offers or discounts available for a specific product.
    * **Navigation and Menus**
        - **Menu Items**: Explain menu items that are not self-explanatory by providing a brief description or the purpose of the menu.
        - **Submenus**: Indicate that a menu item has additional options or submenus available.
    * **Charts and Data Visualisations**
        - **Data Details**: In interactive graphs, display specific details of the data point, such as exact values, percentages, or descriptions.
        - **Axis Explanations**: Provide descriptions or units of measure for the axes of a chart.
    * **Interactive Elements**
        - **Buttons and Controls**: Provide information about what a specific button or control does, especially if the action is not obvious.
        - **Progress Indicators**: Explain the current status or purpose of a progress indicator.

    ## Accessibility

    Considerations of the tooltip:
    - The position will change automatically when the size of the tooltip does not fit in the window.
    - By default the width will be 200px when the multiline property is true.
    - The positions are case sensitive, it will only render `top`, `right`, `left` or `bottom`.
