    ## Slots

    | Name | Description |
    | ---- | ----------- |
    | `default` | The default content of the button (typically used for the label) |
    | `icon` | Icon content that appears before the label |
    | `label` | Custom label content (when `customLabel` is true) |

    ## Accessibility

    The checkbox button component follows accessibility best practices:

    - Uses proper ARIA attributes (`role="checkbox"`, `aria-checked`, `aria-disabled`)
    - Supports keyboard navigation and interaction (Space and Enter keys)
    - Maintains proper focus states
    - Provides appropriate visual states (checked, unchecked, disabled)

    ## Events

    | Event | Detail | Description |
    | ----- | ------ | ----------- |
    | `change` | `{ checked: boolean }` | Fired when the checkbox button state changes |
