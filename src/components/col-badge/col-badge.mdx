    <Title>Badge</Title>
    The Colibri Badge component is used to inform merchants of the status of an object or an action that has been taken.

    <Subtitle>How to use it</Subtitle>
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColBadge } from '@telesign/colibri';
        import '@telesign/colibri/styles/fonts/segoe-ui.css';
        import '@telesign/colibri/styles/fonts/courier.css';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColBadge]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-badge>
          <col-icon slot="icon" size="12px" name="emoji-circle"></col-icon>
          Text
        </col-badge>
        ```

    <Subtitle>When to use it</Subtitle>
    The "badge" component in design has multiple purposes and can be used in a variety of contexts to enhance the user interface and user experience. Here are some common use cases:

    - **Status Indicators** - Show the status of an element or process, such as online/offline status, availability or task completion.
    - **Categorization or Labelling** - Tag items with categories or labels for easy identification and filtering.
    - **Counts and Totals** - Display counts or totals related to an item
    - **Priority Indicators** - Highlight the priority or urgency of an item.
    - **Interactive Elements** - Use badges as interactive elements that users can click on to see more details or perform actions.
