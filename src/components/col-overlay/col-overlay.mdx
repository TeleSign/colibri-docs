    <Title>Overlay</Title>
    The Colibri Overlay component creates a backdrop and positions content over the page. It's the foundation for modals, dialogs, drawers, and other overlay patterns.

    <Callout variant="info" icon="💡">
      This component is commonly used as a building block by other Colibri components. For example, the [Drawer component](/story/organisms-drawer--default) uses Overlay internally to handle the backdrop, focus management, and escape key behavior.
    </Callout>

    <Subtitle>How to use it</Subtitle>
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColOverlay } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColOverlay]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-overlay active>
          <div>Your overlay content here</div>
        </col-overlay>
        ```

    <Subtitle>When to use it</Subtitle>
    The Overlay component is a versatile foundation for various UI patterns:

    - **Modal Dialogs** - Center-aligned overlays with backdrop for important interactions
    - **Drawers/Sidebars** - Edge-aligned panels (see [Drawer component](/story/organisms-drawer--default))
    - **Loading States** - Full-screen loading indicators
    - **Tooltips/Popovers** - Contextual overlays without backdrop
    - **Image Lightboxes** - Full-screen image viewers
    - **Custom Overlays** - Any content that needs to appear above the main page

    <Subtitle>Usage Examples</Subtitle>

    ### Basic Modal Pattern
    ```html
    <col-overlay active>
      <div class="modal-content">
        <h2>Modal Title</h2>
        <p>Modal content goes here</p>
        <button onclick="closeOverlay()">Close</button>
      </div>
    </col-overlay>
    ```

    ### Loading Overlay
    ```html
    <col-overlay active persistent nofocustrap>
      <div class="loading-spinner">
        <span>Loading...</span>
      </div>
    </col-overlay>
    ```

    ### Tooltip/Popover (no backdrop)
    ```html
    <col-overlay active nobackdrop nocentered>
      <div class="tooltip" style="position: fixed; top: 100px; left: 200px;">
        Tooltip content
      </div>
    </col-overlay>
    ```

    ### How Other Components Use Overlay

    The Overlay component is used internally by several Colibri components:

    #### Drawer Component Example
    The [Drawer component](/story/organisms-drawer--default) uses Overlay with specific settings:
    ```html
    <!-- Internal implementation of col-drawer -->
    <col-overlay
      active
      nocentered
      nofocustrap
      @overlay-click-outside=${handleClose}
      @overlay-escape=${handleClose}
    >
      <div class="drawer-panel">
        <!-- Drawer content -->
      </div>
    </col-overlay>
    ```

    <Subtitle>JavaScript API</Subtitle>

    ### Opening and Closing Programmatically
    ```javascript
    const overlay = document.querySelector('col-overlay');

    // Open overlay
    overlay.active = true;
    // or
    overlay.setAttribute('active', 'true');

    // Close overlay
    overlay.active = false;
    // or
    overlay.removeAttribute('active');

    // Listen for close events
    overlay.addEventListener('overlay-click-outside', (e) => {
      console.log('Clicked outside overlay');
    });

    overlay.addEventListener('overlay-escape', (e) => {
      console.log('Escape key pressed');
    });
    ```

    ### Updating Focus Trap
    If you dynamically change the overlay content:
    ```javascript
    const overlay = document.querySelector('col-overlay');

    // After adding new focusable elements
    overlay.updateFocusTrap();
    ```

    <Subtitle>Accessibility</Subtitle>

    The Overlay component includes comprehensive accessibility features:

    - **Focus Trap**: Keeps keyboard focus within the overlay when active
    - **Escape Key**: Closes the overlay when Escape is pressed (unless persistent)
    - **ARIA Attributes**: Proper `role="dialog"`, `aria-modal`, and `aria-hidden` attributes
    - **Scroll Lock**: Prevents body scroll when overlay is active
    - **Backdrop Click**: Closes overlay when clicking outside (configurable)

    <Subtitle>Best Practices</Subtitle>

    - **Focus Management**: Use the built-in focus trap for modal dialogs
    - **Escape Handling**: Allow users to close with Escape key unless critical action required
    - **Backdrop Usage**: Include backdrop for modal interactions, hide for tooltips
    - **Loading States**: Use `persistent` for loading overlays to prevent accidental dismissal
    - **Z-Index Management**: Use the `z-index` prop to manage stacking order
    - **Content Styling**: Always style the content within the overlay (background, padding, etc.)
