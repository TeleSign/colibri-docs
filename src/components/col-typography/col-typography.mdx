    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColTypography } from '@telesign/colibri';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColTypography]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-typography variant="heading" element="h1">Page Title</col-typography>
        ```

    ## When to use it
    The Typography component provides consistent text styling for various contexts:

    - **Headings** - For page titles, section headers, and content organization
    - **Labels** - For form controls, with support for required and disabled states
    - **Display** - For large, prominent text elements that need visual emphasis
    - **Helper** - For providing additional context or assistance, including error messages
    - **Links** - For interactive text elements that navigate to new content
    - **Code** - For displaying inline code snippets or technical content
    - **Caption** - For smaller supporting text like image captions or secondary information
    - **Subheading** - For section subtitles or dividing content groups

    <Canvas of={ColTypographyStories.Subheading} />

    Alternatively, you can set the `element` attribute to an specific HTML tag:

    ```html
    <col-typography variant="subheading" element="p">Subheading</col-typography>
    ```

    While this won't affect the visual size of the Subheading text, it's a key feature for ensuring semantic HTML.     <h4>Sizes</h4>

    **Basic version:**
    <Canvas of={ColTypographyStories.Label} />

    **With icon:**
    <Canvas of={ColTypographyStories.LabelWithIcon} />

    **With required indicator:**
    <Canvas of={ColTypographyStories.LabelWithRequiredIndicator} />

    <Canvas of={ColTypographyStories.LabelWithDisabledState} />

    While the `variant="label"` attribute styles the text appropriately for a label, you can control the specific HTML tag rendered using the `element` attribute. For optimal semantic HTML and accessibility, especially when associating the label with a form control, it is strongly recommended to set `element="label"` as shown in the code snippets above and as follows:

    ```html
    <col-typography variant="label" element="label">Label</col-typography>
    ```

    If a generic inline label is needed (not directly tied to an input), using `element="span"` is also possible:

    ```html
    <col-typography variant="label" element="span">Label</col-typography>
    ```

    This choice primarily affects the document structure and accessibility, not the visual appearance provided by the `variant`.

    <h4>Sizes</h4>
    The Label variant only offers one size: `12px`.
