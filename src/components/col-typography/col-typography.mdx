    ## How to use it
    1. Install the packages:
        ```bash
        npm install @telesign/colibri
        ```
    2. Import the dependencies:
        ```typescript
        import { registerColibriComponents, registerAllComponents, ColTypography } from '@telesign/colibri';
        import '@telesign/colibri/styles/styles.css';
        ```
    3. Register the web components:
        ```typescript
        // Option 1: Register specific components
        registerColibriComponents([ColTypography]);

        // Option 2: Register all Colibri components
        registerAllComponents();
        ```
    4. Use it in your HTML:
        ```html
        <col-typography variant="heading" element="h1">Page Title</col-typography>
        ```

    ## When to use it
    The Typography component provides consistent text styling for various contexts:

    - **Headings** - For page titles, section headers, and content organization
    - **Labels** - For form controls, with support for required and disabled states
    - **Display** - For large, prominent text elements that need visual emphasis
    - **Helper** - For providing additional context or assistance, including error messages
    - **Links** - For interactive text elements that navigate to new content
    - **Code** - For displaying inline code snippets or technical content
    - **Caption** - For smaller supporting text like image captions or secondary information
    - **Subheading** - For section subtitles or dividing content groups

      **Icon with Tooltip Integration**

      Icons slotted into typography components can be wrapped with `col-tooltip` to provide additional context on hover. This pattern is useful for providing explanatory information without cluttering the UI.

      ```html
      <col-typography variant="heading" element="h1">
        Page Title
        <col-tooltip slot="icon" position="top">
          <col-icon name="info-circle" size="30"></col-icon>
          <span slot="tooltip-content">Additional information about this heading</span>
      ```

    <h4>Sizes</h4>
    The Heading variant offers 6 distinct sizes, corresponding to the standard HTML heading tags from `h1` to `h6`. This size is set using the `element` attribute on the component. For example:

    ```html
    <col-typography variant="heading" element="h1">Page Title</col-typography>
    ```

    The sizes are as follows:
    - `h1`: `54px`
    - `h2`: `42px`
    - `h3`: `32px`
    - `h4`: `28px`
    - `h5`: `20px`
    - `h6`: `16px`

    While the `variant="label"` attribute styles the text appropriately for a label, you can control the specific HTML tag rendered using the `element` attribute. For optimal semantic HTML and accessibility, especially when associating the label with a form control, it is strongly recommended to set `element="label"` as shown in the code snippets above and as follows:

    ```html
    <col-typography variant="label" element="label">Label</col-typography>
    ```

    If a generic inline label is needed (not directly tied to an input), using `element="span"` is also possible:

    ```html
    <col-typography variant="label" element="span">Label</col-typography>
    ```

    This choice primarily affects the document structure and accessibility, not the visual appearance provided by the `variant`.

    **Non-anchor elements as links:**
    <Canvas of={ColTypographyStories.DivAsLink} />

    For semantic HTML, it is recommended to set the `element` attribute to `a` as shown in the code snippets above and as follows:

    ```html
    <col-typography variant="link" element="a">Link</col-typography>
    ```

    However, you can also use other HTML elements as interactive links. When you set `variant="link"` with any element (like `div`, `span`, `p`, etc.), the component automatically provides full link functionality:

    - **Accessibility**: Proper keyboard navigation and screen reader support
    - **Navigation**: Click handling for URLs, new tab opening, and downloads
    - **Visual feedback**: Cursor changes and hover states
    - **State management**: Disabled state handling and proper focus management

    ```html
    <col-typography variant="link" element="div" href="https://example.com" newtab>
      Clickable div that opens in new tab
    </col-typography>
    ```

    This is particularly useful when you need to maintain specific HTML structure while still providing link functionality.

    <h4>Sizes</h4>
    The Link variant offers 2 different sizes. The size is set using the `size` attribute on the component:

    ```html
    <col-typography variant="link" element="a" size="md">Link</col-typography>
    ```

    The sizes are as follows:
    - `md`: `14px`
    - `sm`: `12px`
