# Colibri Monorepo Installation Guide

This guide will walk you through the process of installing and setting up the Colibri monorepo, which contains various packages including the core library, icons, documentation, and examples.

## Prerequisites

Before you begin, ensure you have the following installed on your system:

- Node.js (version compatible with npm@10.9.2)
- Git
- npm (version 10.9.2 or higher)

## Installation Steps

### 1. Clone the Repository

First, clone the repository with its submodules:

```bash
# Clone the main repository
git clone ssh://git@bitbucket.c11.telesign.com:7999/dev/colibri-project.git

# Navigate to the project directory
cd colibri-project

# Initialize and update submodules
git submodule init
git submodule update
```

### 2. Submodules Structure

The monorepo includes the following submodules:

- `packages/colibri` - Core library
- `packages/colibri-icons` - Icon package
- `apps/colibri-docs` - Documentation site
- `examples/react-ts` - React TypeScript example
- `examples/vue-ts` - Vue TypeScript example

### 3. Install Dependencies

Install all dependencies across the workspaces:

```bash
npm install
```

## Available Scripts

The monorepo includes several npm scripts to help you develop and build the project:

### Development

- Start all packages in development mode:
```bash
npm run dev
  ```

- Start only the React example:
```bash
npm run dev:react
  ```

### Building

- Build all packages:
```bash
npm run build
  ```

- Build only the packages (excluding documentation):
```bash
npm run build:packages
  ```

- Build only the documentation:
```bash
npm run build:docs
  ```

### Code Quality

- Run linting:
```bash
npm run lint
  ```

- Fix linting issues:
```bash
npm run lint:fix
  ```

- Format code:
```bash
npm run format
  ```

## Turborepo Configuration

The project uses Turborepo for managing the monorepo. Key configurations include:

- Build tasks are configured to run in the correct order with dependencies
- Development tasks are set to persistent mode
- Cache is disabled for build tasks to ensure fresh builds
- Linting and formatting tasks are configured for code quality maintenance

## Troubleshooting

If you encounter issues with submodules:

1. Ensure all submodules are properly initialized:
```bash
git submodule update --init --recursive
   ```

2. If a submodule is out of date:
```bash
git submodule update --remote
   ```

3. For build issues, try cleaning the project:
```bash
npm clean
rm -rf node_modules
npm install
   ```

## Next Steps

After installation, you can:

1. Explore the example React application in `examples/react-ts`
2. Check out the documentation site in `apps/colibri-docs`
3. Start developing with the core library in `packages/colibri`

For more detailed information about each package, refer to their individual README files.

## Development Workflow

### Local Development Setup

1. **Initial Setup**
- Clone all required submodules:
```bash
git submodule update --init --recursive
     ```
- Install dependencies in all workspaces:
```bash
npm install
     ```
- Build all packages initially:
```bash
npm run build:packages
     ```

2. **Development Server**
- For full-stack development:
```bash
npm run dev
     ```
- For React example only:
```bash
npm run dev:react
     ```

### Working with Packages

1. **Core Library Development (`packages/colibri`)**
- Changes in the core library will automatically trigger rebuilds in dependent packages
- Test your changes using the React example
- Ensure all tests pass before committing:
```bash
cd packages/colibri
npm run test
     ```

2. **Icon Package Development (`packages/colibri-icons`)**
- When adding new icons:
1. Place SVG files in the appropriate directory
2. Run the icon generation script
3. Build the package
4. Update documentation if needed

3. **Documentation Development (`apps/colibri-docs`)**
- Run documentation locally:
```bash
cd apps/colibri-docs
npm run dev
     ```
- Preview production build:
```bash
npm run build:docs
npm run preview
     ```

### Code Quality Workflow

1. **Before Committing Changes**
```bash
# Format your code
npm run format

# Run linting
npm run lint

# Fix automatic linting issues
npm run lint:fix
   ```

2. **Testing Changes**
- Test in the React example project
- Verify changes in the documentation
- Check cross-package compatibility

### Package Dependencies

1. **Adding New Dependencies**
- To a specific package:
```bash
cd packages/[package-name]
npm install [dependency-name]
     ```
- To the root project:
```bash
npm install -W [dependency-name]
     ```

2. **Updating Dependencies**
- Update all packages:
```bash
npm update
     ```
- Update specific package:
```bash
npm update [package-name]
     ```

### Version Control Workflow

1. **Working with Submodules**
- Update all submodules:
```bash
git submodule update --remote
     ```
- Commit changes in a submodule:
```bash
cd [submodule-directory]
git checkout -b feature/new-feature
# Make changes
git commit -am "feat: add new feature"
git push origin feature/new-feature
     ```
- Update main repository to point to new submodule commit:
```bash
cd ../
git add [submodule-directory]
git commit -m "chore: update submodule reference"
     ```

2. **Branch Management**
- Create feature branch:
```bash
git checkout -b feature/your-feature
     ```
- Keep branches up to date:
```bash
git fetch origin
git rebase origin/main
git submodule update --recursive
     ```

### CI/CD Integration

1. **Before Creating a Pull Request**
- Ensure all builds pass:
```bash
npm run build
     ```
- Check documentation updates:
```bash
npm run build:docs
     ```

2. **Release Process**
- Update package versions
- Generate changelogs
- Create release tags
- Push updates to all submodules

### Performance Optimization

1. **Build Optimization**
- Use Turborepo's cache when appropriate
- Monitor build times and dependencies
- Optimize package bundling configurations

2. **Development Tips**
- Use `dev:react` for faster feedback when working on UI components
- Leverage Turborepo's task dependencies for efficient builds
- Monitor package sizes and dependencies
