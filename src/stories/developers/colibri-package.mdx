## Installation

```bash
npm install @tls-ds/colibri
```

## Features

- Built with Lit components for efficient web components
- Advanced theming system with light and dark modes
- CSS token generation system
- TypeScript support
- Modern build system using Vite
- ESLint and Prettier integration
- Path aliases for better import organization

## Project Structure

```

│   ├── styles/

```

## Development

### Setup Development Environment

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The development server will start at `http://localhost:3000` with HMR enabled.

### Available Scripts

- `npm run dev`: Start development server
- `npm run preview`: Preview production build
- `npm run build`: Build package for production
- `npm run build:css`: Generate CSS files from tokens
- `npm run lint`: Run ESLint
- `npm run lint:fix`: Fix ESLint issues
- `npm run format`: Format code with Prettier

## Building

The build process includes several steps:

1. TypeScript compilation
2. Vite bundle generation
3. CSS token generation

```bash
npm run build
```

### Build Configuration

The build system uses Vite with the following configuration:

- ES modules output
- Tree-shaking enabled
- Source maps generation
- TypeScript declaration files (d.ts)
- Minification with Terser
- Module preservation for better tree-shaking

## Theming System

### Token Structure

The theming system uses CSS custom properties with a structured naming convention:

```css
--col-[category]-[property]
```

### Theme Files

Three types of theme files are generated:

1. `global.css`: Global tokens and reset styles
2. `themes/light.css`: Light theme tokens
3. `themes/dark.css`: Dark theme tokens
4. `themes/system.css`: System preference-based theme

### Using Themes

Apply themes using the `data-theme` attribute:

```html
<body data-theme="light">
  <!-- Light theme -->
</body>

<body data-theme="dark">
  <!-- Dark theme -->
</body>

<body data-theme="system">
  <!-- System preference theme -->
</body>
```

## CSS Generation

The CSS generation system includes:

### Token Processing

- Converts design tokens to CSS custom properties
- Handles nested token structures
- Processes dynamic token values
- Maintains token references

### Build Features

- Minification for production
- Source maps for development
- Browser compatibility targets
- Automatic directory creation
- Error handling

### Usage Example

```javascript
const generator = new TokenToCSSGenerator({
  outputDir: 'dist/styles',
  minify: true,
  sourceMap: false,
  globalTokens: tokens
});

await generator.generateGlobalFile();
await generator.generateThemeFile('light', lightTokens);
```
